# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [semantic versioning](https://semver.org/). Changes to the C ABI are called out separately.

## Unreleased (0.2.0)

### Added

- `mux` feature (opt-in; a default build compiles none of it): transport stream write primitives in `mpegts::mux`, writing whole packets into caller-provided sinks without allocating.
  - `TsWriter`: the packets of one PID, with continuity counter, payload_unit_start_indicator, adaptation fields (PCR, discontinuity, random access, priority), adaptation field stuffing for PES and 0xFF fill for sections, adaptation-field-only packets, `NULL_PACKET`.
  - `ProgramTables`: PAT (with the network PID) and PMTs for any number of programs, descriptors, version numbers bumped modulo 32 on every change, CRC-32/MPEG-2, the 1021-byte section_length limit, PID conflict checks, transactional changes; `ProgramTables::from_report` rebuilds an input's tables from a demuxer `Report`. Allocation-free section builders `write_pat_section`, `write_pmt_section`, `write_descriptor`.
  - `PesWriter` and `PesUnit`: PES packets with PTS/DTS (33-bit wrap, marker bits), real `PES_packet_length` for everything but oversized video, splitting of oversized non-video units, and three carriages (`Carriage::Pes`, `Carriage::MetadataCells`, `Carriage::AsyncKlv`).
  - Metadata access unit cells (`CellHeader`, `CellFragment`): per-PID sequence numbers (DECISIONS X-8; `CellNumbering::PerAccessUnit` numbers each access unit's cells from 0 instead, for receivers such as MediaMTX that require it, set with `PesWriter::set_cell_numbering` or `SyncKlvOptions::cell_numbering`), fragmentation of access units above 65,522 bytes over several PES packets with the access unit's PTS, random_access_indicator on complete and first cells.
  - KLV carriage presets per MISB ST 1402.2 and SMPTE RP 217 and `docs/standards/DECISIONS.md`: `StreamSpec::klv_sync` / `klv_sync_with` (stream_type 0x15, stream_id 0xFC, metadata_descriptor and metadata_STD_descriptor, optional registration descriptor, several services per stream) and `StreamSpec::klv_async` (stream_type 0x06, stream_id 0xBD, "KLVA" registration, one KLV item per PES).
  - `MuxError`, `PacketSink`, `SliceSink`.
  - `Injector`: pass-through KLV injection into an existing transport stream, synchronous or asynchronous per MISB ST 1402.2. Only PID 0 (the input's PAT, resent unchanged), the target PMT PID (PMT rewritten with the KLV entry, version + 1, new CRC) and the KLV PID change; PAT and PMT copies are added so neither is more than `psi_interval_ms` apart. Synchronous units are queued in PTS order and sent within the T-STD window (990 ms to 1 ms before their PTS by default), right before their video frame; late units and units across a time base discontinuity are dropped and counted. `ExistingKlv::Keep` joins an existing synchronous stream as a new metadata service (continuity counters renumbered, access unit bytes and cell headers untouched; with per-stream cell numbering the cells are renumbered too), `Replace` removes the program's KLV (keeping a PCR it carries), `Fail` refuses. `RateMode::Vbr` adds packets; `RateMode::Cbr` keeps the packet count and every packet's position, filling null and consumed packets, and fails or drops units (`OnOverflow`) when there is no room. Byte input with an internal `PcrTimeline` (`push`) or pre-timed packets (`push_packet`), a frame callback that runs right before each video frame (`push_with`, `finish_with`, `Units`), `insert`, `end_input_with` (process what is held, then insert the last units), `finish`, `target`, `clock`, `stats` (`InjectStats`), `pop_event` (`InjectEvent`), `InjectConfig`, `InjectError`. Bounded memory, no allocation in steady state.
  - `FrameReorder`: video frames from decode order back to presentation order, for per-frame metadata with B-frames.
  - Video SEI user data in the injector (MUXING_PLAN 6.8, `docs/standards/st1402-time.md` D-12 to D-14): `InjectConfig::video_sei` (`VideoSei::Off`, the default, never touches video; `Scan`; `Write`), `InjectConfig::video_sei_max_prefix`. With `Scan` or `Write` the frame callback runs once the access unit's prefix (before its first VCL NAL unit) is read; `Units::user_data()` gives its SEI user_data_unregistered messages (H.264, H.265) or MPEG-2 user_data, `Units::video_prefix()` (`VideoPrefix`) what was read. `Units::write_user_data(uuid, payload, replace)` (H.264 0x1B and H.265 0x24 only; other video fails with `InjectError::Unsupported` when the target is chosen) rewrites a matching message in place or inserts a new SEI NAL unit before the first VCL NAL unit (after the AUD, parameter sets and existing SEI, before an H.264 prefix NAL unit, H.265 TemporalId of the slice), with emulation prevention. The PES is re-packetized: adaptation field stuffing first, then added video packets (VBR) or null packets of the PES, held whole (CBR, packet count kept, `OnOverflow` when there is no room); PES_packet_length rewritten when not 0, video continuity counters renumbered, PTS, DTS and PCRs unchanged, every other PID byte-identical. New `InjectError::UserData`, `InjectWarning::UserDataSkipped` (`UserDataSkip`), `InjectStats` fields `frames_scanned`, `user_data_found`, `user_data_inserted`, `user_data_rewritten`, `user_data_skipped`, `video_packets_added`, `video_slots_filled`, `Target::video_stream_type` and `Target::video_codec`, `MAX_USER_DATA_PAYLOAD`, `DEFAULT_VIDEO_SEI_MAX_PREFIX`.
  - Zero-latency clock for live input: `InjectConfig::clock` (`ClockMode::Interpolate`, the default, or `ClockMode::Extrapolate`, which holds nothing for the clock, so with video SEI off every packet pushed is written before `push` returns).
  - M2TS: `InjectConfig::record` (`RecordFormat::Ts` or `RecordFormat::M2ts`). 192-byte records in (`push` frames at 192 bytes, `Injector::push_record`, `push_record_with`) and out (`PacketSink::record`, a provided method that `Vec<u8>` and `SliceSink` implement for whole records; `RecordFn` for closures; `Record`, `M2TS_RECORD_SIZE`). Input records keep their TP_extra_header; added packets get the next record's copy_permission_indicator and an arrival_time_stamp interpolated between their neighbours.
- Read-side utilities (no feature needed): `PacketHeader` (TS header and adaptation field), `PesHeader` (PES header fields and timestamps), `PcrTimeline` (program clock time of every packet, interpolated between PCRs, or extrapolated without holding anything with `PcrTimeline::with_mode` and `ClockMode::Extrapolate`), `pts_delta`, `pcr_delta`, `PTS_WRAP`, `PCR_WRAP`, `NULL_PID`.
- `nal` module (no feature needed): H.264, H.265 and MPEG-2 video at the level of NAL units: `VideoCodec`, `nal_units` (Annex B start codes of 3 and 4 bytes), `remove_emulation_prevention` and `add_emulation_prevention`, `sei_messages` (payloadType and payloadSize with 0xFF extension bytes, several messages per NAL unit), `find_user_data` (`UserData`, `UserDataPosition`: SEI user_data_unregistered and MPEG-2 user_data with their identifier, payload and position), `user_data_sei` and `replace_sei_payload` to build or rewrite an SEI NAL unit. Bounded work, no panics on any input.
- `capi` feature, on by default, for the C ABI; without it the library is compiled with `#![forbid(unsafe_code)]`.
- Example `mux`, which writes a synthetic stream with H.264 video and both KLV carriages.
- Fuzz harness and cargo-fuzz target `mux`; the `capi` harness also drives the write side.
- Fuzz harness and cargo-fuzz target `inject`; a conformance checker for injected streams in the tests (`tests/harness/check.rs`), and tests against the patched FFmpeg (`MPEGTS_FFPROBE`, `MPEGTS_FFMPEG`) and TSDuck (`MPEGTS_TSDUCK`, run in CI).
- Fuzz harness and cargo-fuzz target `nal`; the `inject` and `capi` harnesses drive video SEI, the extrapolating clock and M2TS. Synthetic H.264, H.265 and MPEG-2 streams for tests (`tests/harness/es.rs`) and `tests/video_sei.rs`, with FFmpeg's `trace_headers` and TSDuck as oracles.

### C ABI

Additive; `MPEGTS_ABI_VERSION` stays 1. The library built by `make` includes the write side (the `mux` feature).

- `MPEGTS_ERR_BUFFER` and the output buffer convention: `(out, capacity, written)`, with `*written` set to the size needed on success and on `MPEGTS_ERR_BUFFER`.
- `mpegts_stream_spec`, `mpegts_stream_spec_pes`, `mpegts_stream_spec_klv_sync`, `mpegts_stream_spec_klv_async`, `MPEGTS_CARRIAGE_*`, `MPEGTS_SPEC_*`.
- `mpegts_program_tables` and its functions: `_new`, `_from_report`, `_free`, `_error`, `_add_program`, `_remove_program`, `_set_pcr_pid`, `_set_network_pid`, `_add_program_descriptor`, `_add_stream`, `_add_stream_descriptor`, `_remove_stream`, `_pat_version`, `_pmt_version`, `_set_pat_version`, `_set_pmt_version`, `_pat_section`, `_pmt_section`, `_write_pat`, `_write_pmt`, `_write_all`, `_continuity_counter`, `_set_continuity_counter`.
- `mpegts_pes_unit`, `MPEGTS_PES_*`, `mpegts_pes_writer` and its functions: `_new`, `_free`, `_error`, `_write`, `_write_adaptation_only`, `_continuity_counter`, `_set_continuity_counter`, `_mark_discontinuity`, `_sequence_number`, `_set_sequence_number`.
- `mpegts_null_packet`.
- The injector: `mpegts_inject_config`, `mpegts_inject_config_default`, `mpegts_inject_config_check`, `mpegts_injector_new`, `_free`, `_error`, `_push`, `_push_packet`, `_insert`, `_end_input`, `_finish`, `_stats`, `_target`, `_clock`, `_pop_event`; inside the frame callback `mpegts_inject_units_insert`, `mpegts_inject_units_clock`, `mpegts_inject_units_target`; the structs `mpegts_inject_unit`, `mpegts_inject_frame`, `mpegts_inject_target`, `mpegts_inject_stats`, `mpegts_inject_event`; the callback types `mpegts_packets_fn` and `mpegts_frame_fn`; constants `MPEGTS_INJECT_*`, `MPEGTS_EXISTING_KLV_*`, `MPEGTS_RATE_*`, `MPEGTS_FRAME_*`, `MPEGTS_TARGET_*`, `MPEGTS_EVENT_*`, `MPEGTS_DROP_*`, `MPEGTS_WARN_*`.
- Status codes `MPEGTS_ERR_FULL` (a queue is full; try again) and `MPEGTS_ERR_STREAM` (the input cannot be processed as configured), and the callback rule in the header's opening comment.
- Video SEI, clock and M2TS for the injector: `mpegts_inject_config` fields `video_sei` (`MPEGTS_VIDEO_SEI_*`), `clock` (`MPEGTS_CLOCK_*`), `record` (`MPEGTS_RECORD_*`) and `video_sei_max_prefix`; `mpegts_inject_frame` flags `MPEGTS_FRAME_SCANNED`, `MPEGTS_FRAME_PREFIX_COMPLETE` and fields `video_codec`, `user_data_count`, `prefix_bytes`; `mpegts_inject_target` fields `video_codec`, `video_stream_type`; seven `mpegts_inject_stats` fields (`frames_scanned` to `video_slots_filled`); `MPEGTS_WARN_USER_DATA_SKIPPED` with `MPEGTS_SKIP_*`; functions `mpegts_inject_units_user_data`, `mpegts_inject_units_write_user_data` (frame callback) and `mpegts_injector_push_record`. With `MPEGTS_RECORD_M2TS` the packet callback receives 192-byte records.
- Cell numbering (DECISIONS X-8): `mpegts_pes_writer_set_cell_numbering` with `MPEGTS_CELLS_PER_STREAM` (0, the default) and `MPEGTS_CELLS_PER_AU` (1), and the injector flag `MPEGTS_INJECT_CELLS_PER_AU`. `mpegts_pes_writer_sequence_number` reports 0 for cells numbered per access unit.

### Changed

- `mpegts_status_string(MPEGTS_ERR_POISONED)` reads "unusable after an internal error", since program tables and PES writers can be poisoned too.
- The CMake package now requires `find_package(mpegts 0.2)`.

## 0.1.0

### Added

- Stream analysis: programs, elementary streams, codec identification (including sync and async KLV), timing, continuity and error counters, for whole buffers and live feeds.
- Extraction of raw packets, PES packets and sections from any stream or table, with bounded, configurable buffers and packet history replay.
- Stable C ABI (`include/mpegts.h`, ABI version 1) with `make install`, pkg-config and CMake support.
- `Subscription::strip_metadata_au` (C: `mpegts_subscription.strip_metadata_au`) to deliver sync KLV without its metadata access unit cell headers.
- Fuzz harnesses for the stable toolchain and cargo-fuzz.
- Examples: `tsinfo`, `extract`, `json`, `throughput` and the C `klv_dump`.
